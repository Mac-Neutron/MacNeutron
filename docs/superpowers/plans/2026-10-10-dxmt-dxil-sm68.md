# DXIL Shader Model 6.8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** DXMT's DXIL translator covers every Shader Model 6.1-6.8 operation its caps require in vertex, pixel, compute and
geometry shaders, and then the device reports Shader Model 6.8 with OPTIONS21's two 6.8 flags and OPTIONS22.

**Architecture:** Fourteen DXMT patches (0040-0053) add the missing lowerings to `src/airconv/dxil`, the descriptor-heap
plumbing to `src/d3d12` and the `R32Uint` views typed float atomics need, one reviewable unit each, each with its own
behaviour test. Patch 0054 flips the reported shader model last, once every feature row passes. New tests are compute
groups with CPU references (`dxmt/tests/expect.py`) and render tests with self-references; refused shaders move to
`dxmt/tests/dxil/reject/`. Every translator task translates SMITE 2's captured shaders and `dxmt/tests/dxbc` offline
before and after (`air=` hashes, `corpus-diff.py`).

**Tech Stack:** C++17 and LLVM 15 (airconv, AIR), Metal (AIR intrinsics, `dxil-translate.mm`), HLSL compiled by the pinned
DXC 1.9.2607 under Wine, llvm-mingw test programs (x64 and ARM64EC), POSIX sh (`check.sh`, `compile.sh`), Python 3
(`expect.py`, `corpus-diff.py`), make.

**Spec:** `docs/superpowers/specs/2026-10-10-dxmt-dxil-sm68-design.md`, which argues from
`.superpowers/brainstorm-sm/research-result.json` (synthesis and explorers; the corrections win) and the rulings
`.superpowers/brainstorm-sm/rulings.md` (S-R1 to S-R8).

All file:line references are at DXMT tree `build/wine-arm64-src/dxmt` HEAD 0593068 (patch 0039) and repo HEAD c8dc702.
Edits to `dxmt/check.sh`, `compile.sh`, `d3d12_dxil_exec.cpp` and the acceptance doc stack up task after task: each edit
also names the text it goes beside, which is what counts once earlier tasks have moved lines.

## Review Focus

1. **A pixel shader's wave operations on partly covered quads** (every triangle edge): helpers left out by default,
   counted with `[WaveOpsIncludeHelperLanes]`. Task 2's `helper` rows, one check per wave op.
2. **2D compute quads that Metal's lane rows don't line up with** (`numthreads(32,2,1)`, `(6,6,1)`): derivatives and
   `QuadReadAcross*` see their 2×2 neighbours. Task 8's `deriv2dwide` and `deriv2dodd`.
3. **A descriptor heap rebound between two dispatches in one command list:** the second dispatch reads the new heap,
   not stale root arguments; and a draw, whose root arguments are staged apart from a dispatch's
   (`d3d12_command_list.cpp:205` and `:209`), sees the heaps too. Task 10's `heap-swap` and `tri-heap`.
4. **`SV_StartVertexLocation` on a non-indexed draw and with a negative `BaseVertexLocation`, direct and through
   `ExecuteIndirect`:** the D3D values. Task 12's `start-*` rows, with `SV_VertexID` checked against D3DMetal first.
5. **`[WaveSize(64)]`, or a 6.8 range without 32:** the pipeline is refused naming the range, never run at 32; a 6.8
   `[WaveSize(32)]` (tag 23 with max 0) is accepted. Task 4's `reject` rows and `wavesize32r`.
